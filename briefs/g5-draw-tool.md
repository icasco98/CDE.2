## Why

Rooms start as rectangles and change only by resize, carve and wall drag. The owner wants free polygons and curved walls: an L drawn by hand, a bay, a round diwaniya. The model is already shape-free; what is missing is the tool and the arc memory.

## The model

1. `Footprint` gains `arcs?: readonly Arc[]` where `Arc = { from: number, to: number, centre: Point, radius: number, clockwise: boolean }`: the polygon vertices `from` through `to` (indices, wrapping) lie on that arc, in the polygon's own frame. `parse.ts` reads it, the invariant checks each arc's indices are in range and its vertices lie on the circle within 1e-6, project file version stays (the field is optional; a file without it reads as before; bump only if you must and say why). Every geometry function keeps working on the polygon and ignores `arcs`; `translateFootprint` keeps them (the frame moves with the polygon), `resizeFromAnchor`, `carveFootprint` and `moveSharedWall` drop them (the polygon changed shape; say so in a comment), `placeInFrame` keeps them.
2. An arc's polygon run is generated by `arcPoints(centre, radius, fromAngle, toAngle, clockwise)` in a new `src/geometry/arcs.ts` at a segment count that keeps the chord error under 5 mm and at least 8 segments per quarter turn; a 5 m circle is 48 or more segments. `exactArea(footprint)` adds each arc's segment area (the circular segment between the chord and the arc) to the polygon's area, so the label and the numbers can show the true figure. The export and the massing keep using the polygon (the massing's prism is faceted, which is fine).

## The tool

3. **Draw.** A "Draw" button on the zoning bar enters draw mode for the selected tray room (or, with no room selected, asks which unplaced room by a small list): click corners on the sheet, snapped to the grid, a rubber line following the pointer; click the first corner or press Enter to close; Escape cancels. Holding `A` before a click makes the next segment an arc bulging outward through the midpoint drag (click, then drag the bulge; release sets the arc), so a semicircular bay is one arc segment. A closed shape becomes the room's footprint (rotation 0), its arcs remembered, its area shown as the exact area. A self-intersecting shape or one under 1 m² is refused with a sentence. The drop rules from G0 apply: over a neighbour the prompt asks Carve or Put back.
4. **Circle.** A "Circle" button: click the centre, drag the radius; the room is a circle of that radius (one arc from index 0 back to 0), snapped to 0.25 m radius steps.
5. **Vertex editing.** With a placed room selected, "Edit points" shows a handle on every vertex and a small `+` at every edge midpoint: drag a vertex to move it (snapped to grid, neighbours' overlap refused as any gesture), click `+` to add a vertex, Delete on a vertex handle removes it (never below three). Editing a vertex that belongs to an arc converts that arc to straight segments (drop the arc, say so in the hint). Every edit is one undo step through `onPlace`.
6. **Labels.** The area label reads the exact area for rooms with arcs, one decimal.

## Export

7. The DXF writes each remembered arc as an `ARC` entity (the writer already supports it) instead of the polyline run, so AutoCAD shows a true curve: split the room's polyline at arc ends, write the straight runs as polylines and the arcs as arcs, all on the room's layer. The PDF draws arcs as the polygon run (fine at 1:100). State the DXF rule in one comment.
